# CodeSphere Lite

A browser-based Python code editor built using Flask, HTML, CSS, and JavaScript.

## 🚀 Live Demo

**Try CodeSphere Lite here:** https://codesphere-lite.onrender.com

Open the live website to explore the editor and test its features.

## Features
- Python code editor
- Run Code interface
- Test Lab
- Recent Runs

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
